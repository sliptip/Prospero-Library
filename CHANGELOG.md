# Изменения

## 0.2.1 — 27.11.2026

- В настройках можно удалить выбранную резервную копию с подтверждением.
- IGDB и SteamGridDB открывают отдельные окна для настройки ключей.

## 0.2.0 — 27.11.2026

- Windows EXE запускает Prospero в трее и открывает библиотеку в браузере.
- Кнопка рядом с номером версии проверяет GitHub Releases, скачивает Windows EXE и перезапускает Prospero.

## 0.1.25 — 27.11.2026

- Поиск DLC использует подтверждённую общую карточку PlayStation Store и проверяет платформу исходного PKG. Frozen Hearth для Nobody Saves the World связывается с уже найденным локальным PS4-пакетом.

## 0.1.24 — 27.11.2026

- Запасной поиск в PlayStation Store распознаёт пометки PS4 и PS5 в названиях изданий. Добавлены проверенные ссылки на стандартные издания Nobody Saves the World и It Takes Two для описаний и оформления.
- Prospero пробует другие адреса после тайм-аута и обновляет карточки, у которых в кэше сохранились сведения без описания.

## 0.1.23 — 27.11.2026

- Для DLC доступны два статуса: «В образе» и «Не добавлено». При первом запуске ранее настроенные и проверенные DLC переходят в «В образе», исключённые — в «Не добавлено». Для строк с неизвестным статусом поле остаётся без отметки.

## 0.1.22 — 25.11.2026

- При несовпадении Content ID в PKG и PlayStation Store Prospero может найти стандартное издание через сайт PlayStation. Подтверждённая карточка магазина используется для оформления и сведений об игре.

## 0.1.21 — 25.11.2026

- Для игр на отключённом диске сохраняются последняя подтверждённая версия с локальным патчем и зелёная галочка, если эта версия актуальна.

## 0.1.20 — 25.11.2026

- Отключённая папка коллекции больше не вызывает ложное уведомление об обновлении игры. Prospero учитывает, что проверенный ранее патч может находиться в недоступной папке.
- После добавления игры вручную или при сканировании Prospero автоматически проверяет последний официальный патч.

## 0.1.19 — 25.11.2026

- В шкафу и списке зелёная галочка отмечает актуальную версию, а янтарная стрелка — наличие более нового патча.
- Описания DLC сначала загружаются с русскоязычной витрины PlayStation Store, даже если дополнение нашлось на другой витрине.
- Поиск оформления принимает изображения с обоих CDN SteamGridDB и сообщает, если сервис отклонил ключ или не нашёл обложек.

## 0.1.18 — 25.11.2026

- Если манифест Sony недоступен, проверка PS4 получает версии патчей с OrbisPatches по Title ID.
- Обложки показываются целиком. Строки с именами локальных PKG отделены от описания дополнения.
- В настройках можно сохранить ключи IGDB и SteamGridDB. Внизу боковой панели показана версия приложения.

## 0.1.17 — 25.11.2026

- Описания DLC и состава изданий загружаются целиком. Ранее сохранённый текст можно заменить кнопкой **Обновить описание** в результатах поиска по PlayStation Store.

## 0.1.16 — 25.11.2026

- Поиск дополнений сверяет список с региональной страницей той же игры, если PlayStation Store связывает издания через общий Concept ID. Найденные DLC объединяются по Content ID.

## 0.1.15 — 25.11.2026

- Prospero ищет оригинальные обложки и сведения о региональных изданиях на подходящих витринах PlayStation Store по точному Content ID.
- Счётчик DLC на полке учитывает найденные PKG и объединяет дубликаты по Content ID.

## 0.1.14 — 25.11.2026

- База, загруженные изображения, резервные копии и журнал по умолчанию лежат в папке `data` рядом с программой.
- Убрана декоративная подпись «Локальная библиотека» из боковой панели.

## 0.1.13 — 25.11.2026

- Сканер читает колоночный вывод `fpkg-cli 3.2.0 ps4-info` и распознаёт отдельные PS4 PKG игры, патчей и DLC по их метаданным.

## 0.1.12 — 25.11.2026

- Отдельные PS4 PKG основной игры, патчей и DLC распознаются при сканировании. Патчи и дополнения отображаются в карточке игры с состоянием файлов. При проверке обновлений учитывается самая свежая версия, доступная в коллекции.
- В редакторе карточки кнопка **Найти в магазине** предлагает DLC и состав изданий из PlayStation Store. Языковые пакеты исключаются. Выбранные сведения сохраняются с карточкой.
- В настройках библиотеки можно скрыть блок **Недавно добавлено**.

## 0.1.11 — 25.11.2026

- PlayStation Store заполняет языки интерфейса и субтитров, а также языки озвучки для соответствующей версии игры. При подтверждённой поддержке русского источник по умолчанию — «Официальная». Когда русского нет, строка источника скрыта.
- В редакторе можно добавить несколько локализаций с названием или автором и языками интерфейса, субтитров и озвучки. Эти группы сохраняются в SQLite вместе с карточкой и входят в резервную копию.

## 0.1.10 — 25.11.2026

- Жанры, издатель, дата выхода и число игроков появляются в шапке карточки сразу после загрузки сведений из PlayStation Store.
- Кнопка **Об игре** открывает описание во всплывающем окне. Русскоязычная страница магазина используется первой. Англоязычное описание при необходимости показывается с подписью языка.
- Сведения об играх сохраняются в SQLite и входят в резервную копию. После первой загрузки они доступны офлайн.

## 0.1.9 — 25.11.2026

- Под шапкой карточки появился сворачиваемый блок **Об игре**. При первом открытии он загружает описание, жанры и издателя с PlayStation Store по Content ID.

## 0.1.8 — 25.11.2026

- В настройках можно добавить несколько папок за один раз. Поддерживаются и подключённые, и временно отключённые диски. Сканирование проверяет вложенные папки и показывает, какой путь недоступен.

## 0.1.7 — 25.11.2026

- Прошивка патча отображается в коротком виде, например `14.20`. Полное значение доступно при наведении и используется для сравнения.
- Строка совместимого патча появляется, когда известна подходящая версия или когда доступные данные позволяют сообщить, что подходящей версии в полученном списке нет.
- В редакторе карточки поля из PKG защищены по умолчанию. Флажок разрешает ручную правку. Сканирование и проверка патчей используют исходный идентификатор пакета.

## 0.1.6 — 25.11.2026

- Проверка патчей PS5 автоматически использует ProsperoPatches, если Sony CDN недоступен или нет манифеста. В журнале видны оба этапа, источник и полученная версия. Добавлен разбор поля `system_ver` из XML Sony.
- В шкафу и списке появился ручной порядок карточек с перетаскиванием или выбором двух карточек. Порядок хранится в SQLite.

## 0.1.5 — 25.11.2026

- В журнале появилась очистка по кнопке. Для запросов к Sony CDN записываются адрес, этап, длительность, HTTP-статус и причины ошибок соединения.
- Для оформления используется оригинальный арт PlayStation Store по Content ID. Обложка и фон Castlevania обновлены файлами из магазина.
- Версия приложения указана в имени ZIP.

## 0.1.4 — 25.11.2026

- Для запросов к Sony CDN в Windows используется системное хранилище сертификатов. Явно заданный CA для HTTPX имеет приоритет.
- При сбое проверки сертификата в журнале отображается доступная причина TLS.

## 0.1.3 — 25.11.2026

- Привязанная к PKG карточка Castlevania получает оформление Konami и дату релиза, если эти поля пусты.
- Отчёт проверки патчей различает ошибки соединения, DNS, TLS и формата манифеста Sony CDN.

## 0.1.2 — 25.11.2026

- Исправлено распознавание приложений PS5 по полям Content type и App type, включая вывод fpkg-cli для Castlevania.
- Журнал диагностики доступен из отчётов и настроек. Записи можно скопировать или скачать в TXT.
- Установленный fpkg-cli можно скопировать в папку Prospero. Эта копия используется первой.

## 0.1.1 — 25.11.2026

- Start.cmd подготавливает локальное Python-окружение и устанавливает недостающие зависимости при запуске.

## 0.1.0 — 25.11.2026

- Локальная SQLite-библиотека с первой карточкой Castlevania: Belmont's Curse.
- Режимы шкафа и списка, поиск, сортировка, фильтры, редактирование, ручное добавление и удаление карточек.
- Ручной импорт PKG через fpkg-cli, переключаемые корни коллекции и отчёт.
- Загрузка оформления, выбор вариантов IGDB и SteamGridDB, локальное сохранение.
- Центр обновлений, ручной ввод проверенных сведений и архив прошлых проверок.
- ZIP-копии базы и изображений, восстановление с защитной копией.
- Исходник Windows-трея и сценарий сборки EXE.
