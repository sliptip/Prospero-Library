# Проверка Prospero Library

## Карточка игры, описание и SQLite 0.1.10

- Проверены жанры, издатель, дата и число игроков в шапке карточки, кнопка **Об игре** и работа окна на узком экране.
- PlayStation Store вернул русское описание Castlevania по Content ID. Для God of War проверено сопоставление русской страницы по идентификатору игры в магазине.
- После перезапуска и восстановления резервной копии описание читается из SQLite. Проверены обновление базы и восстановление резервной копии версии схемы 1.

## Блок «Об игре» 0.1.9

- Проверена загрузка полного описания Castlevania: Belmont's Curse с действующей страницы PlayStation Store. Разбивка на абзацы, жанры и издатель читаются из данных товара.
- В Chromium проверены исходно свёрнутый блок, открытие с клавиатуры и сворачивание. Повторное раскрытие в той же карточке использует уже загруженный текст. У карточки без Content ID блока нет.

## Несколько папок и переезд коллекции 0.1.8

- В Chromium проверено добавление двух путей из одного поля. Сканирование в тесте нашло PKG во вложенных папках обоих путей.
- При недоступности одного пути сканирование продолжилось по второму. Прежняя карточка осталась в библиотеке. После переназначения пути к той же структуре папок файл стал доступен без повторного разбора пакета.

## Отображение прошивки и поля PKG 0.1.7

- В Chromium проверено, что полная прошивка `14.20.00.07` показывается как `14.20`. Строка совместимости скрывается до получения данных и показывает результат после проверки.
- Проверены блокировка полей из PKG, включение флажка, сохранение правки, повторный импорт без дубля и проверка обновлений по исходному Title ID пакета.

## Онлайн-проверка и ручной порядок 0.1.6

- При HTTP 503 от Sony CDN приложение получило три версии Castlevania (PPSA35399) с ProsperoPatches по HTTPS. Последняя версия 01.001.004 требует 14.20.00.07. Среди трёх полученных версий совместимой с 13.60 нет.
- Проверены перетаскивание в шкафу, выбор двух карточек в списке и сохранение порядка после перезагрузки страницы и сервера.

## Журнал и оформление 0.1.5

- Проверены очистка журнала через интерфейс и запись новых событий после очистки.
- Проверены запись сетевой причины ошибки и скрытие учётных данных из URL прокси.
- Подтверждён разбор публичной карточки Castlevania PlayStation Store по Content ID. В архиве оригинальный портретный арт и фон Game Hub.

## TLS в 0.1.4

- Проверен выбор системного SSL-контекста для Windows с обязательной проверкой сертификата и имени хоста. Проверена передача явных настроек CA в HTTPX.
- Тесты выполнены в Linux. Соединение с Sony CDN через системное хранилище Windows проверяется при повторном запуске на целевом компьютере.

## Дополнение карточки и проверка патчей 0.1.3

- Проверен импорт Castlevania в пустой каталог. Карточка получает дату релиза и оформление из комплекта приложения. Явно очищенная пользователем дата остаётся пустой.
- Проверено различение ошибок DNS и некорректного XML в отчёте и журнале. Сетевой запрос к манифесту Castlevania из среды разработки вернул HTTP 503.

## Импорт и журнал 0.1.2

- Регрессия классификации проверена на фрагменте реального вывода Windows fpkg-cli для Castlevania. Тест включал отдельные пакеты патчей и DLC.
- Проверены открытие журнала из ошибки сканирования и выгрузка TXT через Chromium.
- Проверены копирование CLI с библиотекой и приоритет локальной копии после перемещения исходной папки. В этом тесте запуск CLI моделировался. Реальный перенос и повторный импорт на Windows нужно подтвердить на целевой машине.

## Запускатор 0.1.1

Проверены чистый запуск после распаковки, повторный запуск с отключёнными индексами pip и восстановление окружения без uvicorn. Тесты выполнялись в Linux через Python-часть запускатора. Запуск Start.cmd через Windows CMD предстоит проверить на целевой машине.

## Пройдено в среде разработки

- Production-сборка React, запуск FastAPI и создание SQLite.
- Chromium на размерах 1440 × 1000, 768 × 1024 и 390 × 844. Проверены шкаф и список, сохранение режима, поиск по Title ID, фильтры, карточка, редактирование, ручное добавление, загрузка локальной обложки и сохранение после перезапуска сервера.
- Создание ZIP-копии и восстановление базы с локальными изображениями.
- Тестовые сценарии импорта PS4 и PS5, повторы без дублей, пропуск DLC, повреждённые файлы, недоступный и переназначенный корень, сохранение правок и неизменность тестовых файлов.
- Тестовые ответы манифеста, совместимый и несовместимый патчи, пропущенная FW, HTTP 404, HTTP 429 и таймаут.

## Требуется проверка на целевой машине

- Реальный вывод `fpkg-cli 3.2.0` при импорте PKG PS4/PS5 и наличие нужных файлов в выборочном извлечении. В тестах сканирования использованы временные файлы и подставной текст CLI.
- Сборка и запуск Windows EXE, повторный старт, корректный выход и автозапуск трея.
- Проверка запроса к Sony CDN и перехода на ProsperoPatches из Windows.
- Поиск IGDB и SteamGridDB с действующими ключами.
- Запуск Castlevania, доступность DLC, языки и сохранения на личной PS5 Pro.

- Дата релиза — [сообщение Konami](https://www.konami.com/games/us/en/topics/3538/). Обложка и фон — [карточка Castlevania в PlayStation Store](https://store.playstation.com/en-us/product/JP0101-PPSA35399_00-CVBCAPP000000000). Права на игровой арт принадлежат правообладателям.
- Подключение внешнего оформления — [документация IGDB](https://api-docs.igdb.com/) и [SteamGridDB API v2](https://www.steamgriddb.com/api/v2).
