# API Prospero Library

Все маршруты ниже имеют префикс `/api`. OpenAPI доступен на `/docs` и `/openapi.json` запущенного экземпляра. Запросы, меняющие данные, поддерживаются в том же origin. Тела запросов JSON, кроме загрузки файлов.

## Карточки

- `GET /health` возвращает имя приложения и версию.
- `GET /logs` возвращает последние строки журнала в поле `text`. Для выгрузки TXT используй `GET /logs?download=true`.
- `DELETE /logs` очищает диагностический журнал и файлы ротации.
- `GET /games` возвращает карточки в сохранённом ручном порядке. `GET /games/{id}` возвращает одну карточку. В обоих ответах есть данные выбранного пакета, DLC и состояние обновлений.
- `GET /games/{id}/about` возвращает описание, жанры, издателя и ссылку PlayStation Store для Content ID игры. Если описания нет, возвращает `null`.
- `POST /games` создаёт карточку. Обязательные поля `title`, `platform` и `title_id`. Дубликат платформы и Title ID возвращает 409.
- `PUT /games/{id}` сохраняет редактируемую карточку. Поле `notes` содержит примечания пользователя. Если `manifest_uri` отсутствует в запросе, сохранённый URL манифеста сохраняется.
- `package_fields` перечисляет поля, заполненные из PKG, а `package_identity` содержит исходные платформу и Title ID. При `edit_pkg_fields: false` сервер берёт эти поля из текущей карточки. При `edit_pkg_fields: true` изменённые платформа и Title ID сохраняются как данные отображения.
- `POST /games/order` меняет местами карточки с ID в полях `source_id` и `target_id` и возвращает список ID в новом порядке. Если карточка отсутствует, запрос возвращает 404.
- `DELETE /games/{id}` удаляет карточку и связанные записи каталога. PKG остаются на диске.
- `POST /games/{id}/artwork?kind=cover` или `?kind=background` принимает одно изображение в поле `file`. Поддерживаются PNG, JPEG и WebP.
- `POST /games/{id}/artwork/search` возвращает найденные варианты оформления. `POST /games/{id}/artwork/select` с полем `token` сохраняет выбранный вариант локально.

## Настройки и задачи

- `GET /settings` и `PUT /settings` читают и сохраняют пути и целевые прошивки, дополнительно возвращая корни коллекции и состояния ключей.
- `POST /settings/cli` проверяет активный CLI.
- `POST /settings/cli/copy` копирует CLI и обнаруженные библиотеки из сохранённого источника в `tools/fpkg-cli`. Настройки возвращают `cli_local: true`, когда Prospero использует локальную копию.
- `POST /roots`, `PUT /roots/{id}` и `DELETE /roots/{id}` управляют корнями. Для создания или переназначения указывается абсолютный `path`.
- `POST /roots/batch` принимает `roots` со списком объектов `{"path": "…"}` и возвращает `ids`. Список добавляется одной операцией.
- `POST /scan` запускает сканирование. `{"force": true}` повторно читает метаданные файлов с совпавшими размером и временем изменения.
- `POST /updates` проверяет всю коллекцию онлайн. Запрос с `?game_id={id}` ограничивает проверку одной карточкой. ProsperoPatches служит запасным источником для PS5.
- `GET /jobs/latest` и `GET /jobs/{id}` возвращают состояние и счётчики. `POST /jobs/{id}/cancel` запрашивает отмену ручной операции.
- `GET /backups` возвращает имена копий, `POST /backups` создаёт копию. `GET /backups/{name}` скачивает архив. `POST /backups/restore` восстанавливает архив по полю `name` и возвращает имя защитной копии.

## Хранение

В `library.db` таблицы `games`, `builds`, `roots` и `files` связывают карточку с версиями пакета и относительными путями. `dlc`, `patch_history`, `checks`, `settings` и `jobs` хранят остальные данные. Пользовательские изображения в `artwork` записываются под именем по хешу содержимого. Для неизвестных значений используется `null`.
