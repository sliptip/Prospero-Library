# Prospero Library

Локальный каталог PS4/PS5. Один процесс FastAPI отдаёт интерфейс React и API. Карточки, настройки и история патчей хранятся в SQLite, а изображения доступны с диска. В новой базе уже есть Castlevania: Belmont's Curse из ТЗ.

## Первый запуск на Windows

Скачай `Prospero-Library-X.Y.Z.zip` в разделе **Releases → Assets** на GitHub.

1. Распакуй весь архив в отдельную папку, например `D:\Prospero-Library`. Нужен Python 3.12 или новее. Интерфейс в `frontend/dist` уже собран.
2. Запусти `Start.cmd`. При первом запуске он создаст `.venv` в папке проекта и установит зависимости. Для первой установки зависимостей нужен доступ в интернет.
3. Когда сервер запустится, открой [http://127.0.0.1:8000](http://127.0.0.1:8000). При занятом порте скопируй `.env.example` в `.env` и задай `PROSPERO_PORT`, например `8001`.

При первом запуске база создаётся в `%LOCALAPPDATA%\Prospero Library`. Для другой папки укажи `PROSPERO_DATA` в `.env`. Для пустой новой базы задай `PROSPERO_EMPTY_LIBRARY=1` до первого старта.

## Добавление игр и импорт PKG

- Ручную карточку можно создать без PKG через **Добавить игру**. Обложку и фон можно загрузить в разделе **Оформление**.
- Для импорта открой **Настройки → Папки коллекции → Добавить папки**. Вставь полные пути, каждый с новой строки. Достаточно указать родительскую папку, чтобы проверить её подпапки. Можно добавить путь на съёмном диске и переназначить его, если буква диска изменилась. Готовая коллекция должна лежать вне `_WorkHard`.
- В **Локальный PKG-парсер** укажи путь к своему `fpkg-cli.exe` или папку установки PSVIETHOA FPKG Builder. Нажми **Сохранить**, затем **Скопировать CLI в Prospero**. Если путь уже сохранён, сразу нажми кнопку копирования. Prospero проверит запуск копии и будет брать парсер из `tools/fpkg-cli`. Эту папку можно переносить вместе с приложением. Для запуска через EXE положи `tools/fpkg-cli` рядом с EXE.
- Если уже используешь переносимый `fpkg-cli`, положи его с нужными соседними библиотеками в `tools/fpkg-cli` и нажми **Проверить CLI**. ZIP Prospero содержит код копирования, CLI берётся из твоей установки.
- Сканирование сопоставляет игру по платформе и Title ID, сохраняет ручные правки и выдаёт отчёт. Отключённый диск оставляет карточки видимыми. Работа с PKG ограничена чтением метаданных и выборочным извлечением оформления PS5 во временную папку. При сомнении в типе пакета сканер передаёт файл в отчёт.
- Для PS4 отдельные файлы игры, обновлений и DLC можно хранить вместе. Сканер различает их по метаданным и связывает по Title ID. Доступные локальные патчи учитываются при сравнении версий.
- В редакторе карточки флажок **Разрешить редактирование полей из PKG** разблокирует данные с диска. Правки сохраняются в карточке. Повторное сканирование и проверка патчей используют платформу и Title ID исходного PKG.
- Для игры с Content ID сканер сначала ищет оригинальные изображения на её странице PlayStation Store. В **Оформлении** доступны варианты из Store, а также из IGDB и SteamGridDB после настройки ключей из `.env.example`. Ручная загрузка работает офлайн.
- В карточке игры с Content ID Prospero сразу загружает жанры, издателя, дату выхода и число игроков с PlayStation Store. Кнопка **Об игре** открывает описание в отдельном окне. Если русский текст недоступен, окно показывает английский с пометкой языка. Полученные сведения сохраняются в SQLite, доступны офлайн и входят в резервную копию.
- В блоке **Локализация** видны языки интерфейса и субтитров и языки озвучки из PlayStation Store. В редакторе кнопка **Добавить локализацию** создаёт группу с названием или автором и отдельными списками языков. У каждой карточки может быть несколько таких групп.
- Для карточки с Content ID в редакторе **Дополнения → Найти в магазине** предлагает DLC и состав изданий, которые публикует PlayStation Store. Можно выбрать отдельные записи. Языковые пакеты пропускаются.

Кнопка **Журнал** есть в отчёте сканирования и проверки обновлений. Журнал также доступен из настроек. Его можно обновить, очистить, скопировать или скачать в TXT. Записи об ошибках чтения PKG показывают имя файла, команду и код возврата CLI. Для Sony CDN доступны этап запроса, длительность, HTTP-статус и вложенная причина ошибки соединения.

## Проверка обновлений

Раздел **Обновления** показывает версию в коллекции, официальную версию и статус источника. Строка совместимости показывает подходящий патч или сообщает, что его нет среди полученных версий. При недостатке данных строка скрыта. Прошивка патча отображается коротко, полное значение видно при наведении. Для PS5 по умолчанию используется прошивка 13.60, для PS4 её можно задать в настройках.

Нажми **Проверить все** на странице обновлений или кнопку обновления в карточке. Prospero использует ссылку на манифест Sony из PKG. Для PS5 при отсутствии ссылки, сбое Sony CDN или пустом ответе приложение запрашивает список патчей по Title ID на ProsperoPatches. В карточке и журнале отображается использованный источник. История сохраняет версии, полученные во время успешных онлайн-проверок.

В Windows Prospero проверяет TLS-сертификаты через системное хранилище. При явной настройке `SSL_CERT_FILE` или `SSL_CERT_DIR` проверка использует указанные сертификаты.

## Порядок карточек

В **Настройки → Библиотека** можно скрыть блок **Недавно добавлено** и сразу открывать коллекцию.

В сортировке коллекции выбери **Ручной порядок**. Перетащи карточку за ручку на другую карточку или нажми ручку и выбери вторую карточку. Карточки поменяются местами. Порядок общий для шкафа и списка, сохраняется в базе и входит в резервную копию.

## Резервная копия и перенос

В **Настройки → Резервные копии** можно создать архив, скачать его и восстановить. Внутри SQLite, настройки и загруженное оформление. PKG лежат отдельно. Перед восстановлением приложение создаёт защитную копию.

Чтобы восстановить скачанный архив на другом ПК, положи его с оригинальным именем в папку `backups` внутри каталога данных. После этого он появится на странице настроек. Корни коллекции можно переназначить из интерфейса. Секреты из `.env` вводятся на новом ПК отдельно.

## Запуск через трей

Исходник трея находится в `launcher/tray.py`. Для сборки Windows EXE из PowerShell нужны Python 3.12+ и Node.js 22.12+.

```powershell
.\scripts\build-windows.ps1
```

Скрипт создаёт `dist\Prospero Library.exe`. Трей открывает браузер, запускает ручные операции, показывает настройки и открывает журнал. Автозапуск можно включить из меню. Для переносимой конфигурации положи `.env` рядом с EXE. Данные сохраняются вне EXE. Сборку и поведение EXE предстоит подтвердить на Windows.

## Сборка интерфейса и разработка

```text
npm --prefix frontend ci
npm --prefix frontend run build
python -m backend
```

Для горячей перезагрузки интерфейса запусти `npm --prefix frontend run dev`. Бэкенд остаётся на порту 8000. Для записи из окна Vite установи в `.env` `PROSPERO_DEV_ORIGIN=http://127.0.0.1:5173`.

Локальный запуск привязан к `127.0.0.1`. Чтобы открыть доступ к серверу из доверенной домашней сети, используй запуск через `python -m backend`, укажи LAN-адрес компьютера в `PROSPERO_HOST` и перечисли разрешённые IP/имена в `PROSPERO_ALLOWED_HOSTS`. Ограничь входящие соединения локальной подсетью в брандмауэре. В этом режиме доступ к каталогу и его редактированию получают устройства, которые могут подключиться к адресу. Для доступа извне используй VPN или прокси с авторизацией.

## Выпуск версии

Версия задаётся в `backend/__init__.py`. При появлении новой версии в `main` GitHub Actions запускает тесты, собирает интерфейс и прикрепляет готовый ZIP к релизу. Текст релиза берётся из соответствующего раздела `CHANGELOG.md`.
